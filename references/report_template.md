### 3.2 成功文章的写作模式

**模式1：总分总结构**
- 开篇：抛出观点/问题
- 中段：3-5个分论点展开
- 结尾：总结+行动号召

**模式2：故事驱动**
- 开篇：引人入胜的场景
- 中段：冲突与解决
- 结尾：升华与启示

### 3.3 可复用的写作框架

```
[Hook] 一句话抓住注意力

[背景] 为什么这个话题重要

[核心内容]

- 要点2：...
- 要点3：...

[总结] 核心观点重申

[行动号召] 引导读者下一步
```
