# 公众号文章深度分析指南

## 数据字段说明

### 文章属性

| 字段 | 说明 | 分析用途 |
|------|------|----------|
| title | 标题 | 分析标题特征与阅读量关系 |
| digest | 摘要 | 分析摘要质量和内容主题 |
| datetime | 发布时间 | 分析最佳发布时段 |
| nickname | 公众号名称 | 分析不同公众号的表现差异 |
| content_url | 文章链接 | 用于获取原文详情 |

### 互动数据

| 字段 | 说明 | 参考基准 |
|------|------|----------|
| read_num | 阅读量 | 主要衡量指标 |
| like_num | 点赞数 | 用户认可度，>1%为优秀 |
| comment_num | 评论数 | 互动深度指标 |

### 派生指标

| 指标 | 计算方式 | 意义 |
|------|----------|------|
| 点赞率 | like_num / read_num × 100% | 内容质量指标，>1% 优秀 |
| 评论率 | comment_num / read_num × 100% | 互动深度，>0.1% 较活跃 |
| 互动率 | (like_num + comment_num) / read_num × 100% | 综合互动质量 |

## 一、标题分析方法

### 1.1 长度分析

**最佳长度参考：**
- 15-25字效果最佳
- 过短(<10字)：信息量不足
- 过长(>30字)：展示不全，影响点击

**分析方法：**
```python
title_length = len(title)
# 按长度分组统计平均阅读量
```

### 1.2 结构模式识别

| 模式 | 特征 | 示例 |
|------|------|------|
| 数字清单 | 包含数字 | "5个技巧"、"3大趋势" |
| 疑问引导 | 问句结尾 | "为什么...？"、"如何...？" |
| 对比冲突 | 对比词汇 | "xx vs xx"、"不是...而是..." |
| 悬念式 | 省略或暗示 | "原来..."、"竟然..." |
| 热点关联 | 热词蹭点 | 结合时事、名人、热门IP |
| 痛点直击 | 精准描述 | 直接点出目标群体痛点 |

### 1.3 情绪词汇分析

**高唤起情绪词：**
- 惊讶类：震惊、没想到、竟然、居然
- 紧迫类：紧急、最后、限时、马上
- 好奇类：揭秘、真相、内幕、秘密
- 共鸣类：终于、果然、原来如此

### 1.4 标题分析输出

```markdown
### 标题分析
- 平均长度：XX字
- 最佳长度区间：XX-XX字
- 数字使用率：XX%
- 问句使用率：XX%

**高阅读量标题特征：**
1. ...
2. ...

**标题模板推荐：**
- [数字] + [好处/方法] + [痛点]
- [疑问] + [目标群体] + [核心利益]
```

## 二、话题归类方法

### 2.1 分类维度

根据关键词领域，选择合适的分类框架：

**通用分类：**
- 知识科普类
- 案例分析类
- 观点评论类
- 工具教程类
- 行业资讯类
- 情感共鸣类

**科技类细分：**
- 产品发布/评测
- 技术教程/入门
- 行业趋势/分析
- 应用场景/案例
- 人物访谈/故事

### 2.2 归类方法

1. **关键词提取**：从标题和摘要中提取关键词
2. **主题聚类**：按关键词相似度归类
3. **人工校验**：审核分类合理性

### 2.3 热度评估

| 类型A | N | X | ⭐⭐⭐⭐⭐ |

## 三、写作风格拆解方法

### 3.1 开篇 Hook 分析

**常见开篇类型：**
| 类型 | 特点 | 示例 |
|------|------|------|
| 故事开场 | 以具体场景/人物引入 | "上周，一位粉丝问我..." |
| 痛点直击 | 直接点出读者困扰 | "你是不是也遇到过..." |
| 数据惊艳 | 用数据制造冲击 | "90%的人都不知道..." |
| 热点关联 | 蹭热点引入正题 | "最近XXX很火，其实..." |
| 反常识 | 打破固有认知 | "你以为XXX，其实..." |

### 3.2 文章结构分析

**常见结构：**
- 总分总：开门见山 → 分点论述 → 总结升华
- 递进式：浅入深出，层层推进
- 故事线：背景 → 冲突 → 解决 → 启示
- 清单式：并列多个要点，独立成章

### 3.3 语言风格评估

| 维度 | 低分 | 高分 |
|------|------|------|
| 口语化 | 书面、正式 | 亲切、对话感 |
| 专业性 | 泛泛而谈 | 深度、有料 |
| 情感化 | 理性、冷淡 | 共鸣、走心 |
| 节奏感 | 冗长、拖沓 | 简练、有力 |

## 四、互动数据分析方法

### 4.1 数据分布统计

```markdown
### 数据概览
- 文章总数：XX篇
- 阅读量范围：X - X
- 平均阅读量：X
- 中位数阅读量：X
- 点赞率均值：X%
```

### 4.2 数据分层

| 层级 | 定义 | 特征分析 |
|------|------|----------|
| Top 20% | 阅读量前20% | 分析成功因素 |
| 中间层 | 阅读量中等 | 分析提升空间 |
| Bottom 20% | 阅读量后20% | 诊断问题原因 |

### 4.3 关联分析

分析数据与内容特征的关联：
- 标题长度 vs 阅读量
- 发布时间 vs 阅读量
- 是否包含数字 vs 阅读量
- 话题类型 vs 阅读量
